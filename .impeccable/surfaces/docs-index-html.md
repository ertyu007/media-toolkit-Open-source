# Surface brief — Clipora project site

**Scope:** Replace `docs/index.html` (single static page, GitHub Pages) with a landing page whose job is promotion and download. **Visitor mode:** Persuade.

**Audience:** Thai Windows 10/11 users arriving from GitHub Releases, plus developers evaluating the repository. **Job:** understand the local-first offer in seconds, trust it, and download the right build. **Proof:** real product capabilities and limits from the repo; no invented screenshots, testimonials, or benchmarks. **Constraints:** version 0.7.1; Thai copy; GPL-3.0-only; no color emoji; no external JS; public/single-item URL scope; must work without motion.

**Chosen direction:** Studio Deck — candidate 3 of 7 grounded directions (media transport deck, broadcast control room, Explorer utility, contact sheet, subtitle station, patchbay, print-shop ticket), fused with the pinned Midnight Amethyst world. Assignment index 3 matched the top-ranked candidate. **Signature interaction:** the hero render deck plays a synthetic job: waveform transport, timecode, stage labels, and progress update across video, audio, URL, and stem jobs; it pauses on focus/hover and becomes a static completed job under reduced motion.

**Unresolved decisions:** none. Version stays 0.7.1.

## Direction contract

**THESIS:** The page is a working render deck, not a feature brochure: the media pipeline is the first thing a visitor sees operating. It refuses the icon-card hero and the screenshot collage.

**OWN-WORLD:** Midnight Amethyst control surface: near-black #0d0d11 ground, raised #15151c panels, 1px #2b2b36 rails, electric violet #8b5cf6 signal with #c4b5fd highlights, amber only for armed states, mint only for completed output. Rounded 14px panels, drawn 1.5px line icons, tabular mono measurement text, IBM Plex Sans Thai display/body, IBM Plex Mono for timecode and logs.

**STORY:** A visitor understands that this is a Windows app that converts and extracts locally, sees the four job types moving through one deck, believes the privacy and safety constraints, then downloads Setup or the portable ZIP.

**FIRST VIEWPORT:** Sticky slim nav. Asymmetric split: left 55% carries the H1 at clamp 2.9–5.4rem over three lines, a 2-line lead, primary download CTA plus a secondary docs link, and a version/size/license line. Right 45% is a 520px-wide render deck with a live waveform, timecode, four queued jobs, one active row, a progress rail, and a synthetic-data label. Background is charcoal with a single violet pool behind the deck and a faint measurement grid.

**FORM:** Studio Deck, position 3 of the ordered list; seed key `52817f33`.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
