# คู่มือผู้ใช้ Clipora

## สารบัญ

1. Clipora ทำอะไร
2. เตรียมเครื่อง
3. เปิดโปรแกรม
4. ดาวน์โหลดจากลิงก์
5. แยกเสียงจากไฟล์ในเครื่อง
6. แยกสเต็มเสียง (เสียงร้อง/ดนตรี)
7. อัปเดต yt-dlp
8. แปลง MP4 / MOV (ProRes)
9. ไฟล์ผลลัพธ์
10. คุณภาพและเวลา
11. ความปลอดภัยและความเป็นส่วนตัว
12. ข้อจำกัดปัจจุบัน

## 1. Clipora ทำอะไร

Clipora รับไฟล์วิดีโอในเครื่องเพื่อส่งให้ FFmpeg แยกเสียงหรือแปลงวิดีโอ และรับ URL สาธารณะเพื่อดาวน์โหลดผ่าน yt-dlp ผลลัพธ์ถูกเขียนไปยังโฟลเดอร์ที่ผู้ใช้เลือก ต้นฉบับในเครื่องไม่ถูกแก้ไข

งานที่รองรับ:

- วิดีโอเป็น MP3, M4A, WAV, FLAC หรือ OPUS
- วิดีโอเป็น MP4/H.264 พร้อม AAC เมื่อมีเสียง
- วิดีโอไม่มีเสียงเป็น MP4 ที่ไม่มี audio stream
- วิดีโอเป็น MOV/ProRes 422 (เหมาะกับ Adobe After Effects)
- แยกสเต็มเสียง (เสียงร้อง/ดนตรี ฯลฯ) บนเครื่องด้วย Demucs
- URL สาธารณะเป็นวิดีโอ MP4/MOV หรือเสียง MP3/M4A/WAV/FLAC/OPUS

ไฟล์ input ที่แสดงใน file picker ได้แก่ MP4, MOV, MKV, AVI, WebM และ M4V ความสำเร็จขึ้นกับ codec ที่ FFmpeg build บนเครื่องรองรับ

## 2. เตรียมเครื่อง

### ผู้ใช้ Windows Setup

ดาวน์โหลด `Clipora-Setup-<version>-x64.exe` จากหน้า Releases ติดตั้งและเปิดโปรแกรม ตัวติดตั้งรวม FFmpeg, yt-dlp และ Deno ไว้ในตัวแล้ว เปิดครั้งแรกเข้าหน้าหลักได้ทันทีโดยไม่ต้องดาวน์โหลดเครื่องมือเพิ่ม

ไม่ต้องติดตั้ง Python ใช้ PowerShell แก้ PATH หรือเปิดด้วย Administrator หากเครื่องมือบางตัวหายหรือเสียหาย เช่น หลังอัปเดตหรือถูกโปรแกรมอื่นลบ ตัวช่วยตั้งค่าจะแสดง flow: หน้า **ยินดีต้อนรับ** → **ข้อตกลง** (อ่านขอบเขตการเชื่อมต่ออินเทอร์เน็ตและการใช้งานสื่อ แล้วกดยินยอม) → **ตรวจสอบ** (รายการ FFmpeg, yt-dlp, Deno พร้อมเวอร์ชันและขนาดดาวน์โหลด) → **ติดตั้ง** (ดาวน์โหลด ตรวจ SHA-256 แล้วติดตั้งลง `%LOCALAPPDATA%\Clipora\tools`) → **เสร็จสิ้น** และเปิดได้จากปุ่ม **เครื่องมือ** มุมขวาบนเช่นกัน หากยกเลิกระหว่างดาวน์โหลด ตัวช่วยจะหยุดอย่างปลอดภัยและไม่ลบเครื่องมือเดิมที่ใช้งานได้

### นักพัฒนาที่รันจาก source

ติดตั้ง Python 3.10+, FFmpeg, yt-dlp และ Deno/Node จากนั้นรัน `python scripts/check_environment.py` เมื่อทุกหัวข้อขึ้น `[OK]` จึงเปิดด้วย `python app.py`

## 3. เปิดโปรแกรม

รุ่น Setup เปิดจาก Start Menu, Desktop shortcut หรือไฟล์ `Clipora.exe` ในโฟลเดอร์ติดตั้ง ผู้ใช้ source เปิดด้วย:

```powershell
python app.py
```

หน้าต่างประกอบด้วย:

- **ไฟล์ในเครื่อง / วางลิงก์**: เลือกชนิดแหล่งที่มา
- ช่องแหล่งที่มา: พาธไฟล์หรือ URL แบบ `http/https`
- **เลือกไฟล์ / วางจากคลิปบอร์ด**: เปิด file picker หรืออ่านลิงก์จาก clipboard
- **เครื่องมือ**: ตรวจ ติดตั้งใหม่ หรือซ่อม FFmpeg, yt-dlp และ Deno รวมถึงติดตั้งเครื่องมือแยกสเต็มเสียง (PyTorch/Demucs)
- **อัปเดต yt-dlp**: ตรวจและอัปเดต yt-dlp เป็นเวอร์ชันล่าสุดจากผู้เผยแพร่ (ตรวจอัตโนมัติหลังเปิดแอป 3 วินาที)
- ข้อมูลใต้พาธ: แสดงชื่อและขนาดไฟล์ที่เลือก หรือแจ้งเมื่อไม่พบไฟล์
- **โฟลเดอร์ปลายทาง**: โฟลเดอร์สำหรับ output
- **เลือกโฟลเดอร์**: เปลี่ยนปลายทาง
- **แยกเสียง / แยกสเต็มเสียง / แปลงเป็นวิดีโอ**: เลือก operation
- **รูปแบบเสียง MP3/M4A/WAV/FLAC/OPUS หรือรูปแบบไฟล์ MP4/MOV**: ตัวเลือกตาม operation
- **คุณภาพ / เฟรมเรต**: เลือกความละเอียด (URL) หรือคุณภาพและ fps (60/30) สำหรับผลลัพธ์วิดีโอ
- Checkbox สิทธิ์: ต้องยืนยันก่อนเริ่มงาน URL
- ปุ่มเริ่ม: เปลี่ยนข้อความตามงานที่เลือก
- **ยกเลิกงาน**: ปุ่มหลักจะเปลี่ยนเป็นคำสั่งนี้ระหว่างประมวลผล
- Progress, เปอร์เซ็นต์ และ status: บอกสถานะปัจจุบัน

ระหว่างประมวลผล Clipora จะล็อกช่องไฟล์ โฟลเดอร์ และตัวเลือกรูปแบบไว้ชั่วคราว เมื่อสำเร็จ ล้มเหลว หรือยกเลิก ระบบจะเปิดให้แก้ไขและเริ่มงานใหม่ได้

อย่าเปิดโปรแกรมด้วย Administrator หากไม่จำเป็น ให้เลือกโฟลเดอร์ที่ user ปกติเขียนได้ เช่น Downloads, Videos หรือโฟลเดอร์งาน

## 4. ดาวน์โหลดจากลิงก์

1. คัดลอก URL สาธารณะที่เป็นรายการเดียว
2. เลือก **วางลิงก์** ในหัวข้อแหล่งที่มา
3. วาง URL ด้วย `Ctrl+V`/`Shift+Insert` หรือกด **วางจากคลิปบอร์ด**
4. เลือกโฟลเดอร์ปลายทาง
5. เลือก **แยกเสียง** แล้วเลือก MP3/M4A/WAV/FLAC/OPUS หรือเลือก **แปลงเป็นวิดีโอ** แล้วเลือกรูปแบบไฟล์ MP4/MOV คุณภาพ และเฟรมเรต
6. ทำเครื่องหมายยืนยันว่าอ่านและยอมรับ **คำปฏิเสธด้านลิขสิทธิ์** แล้ว และจะไม่ดาวน์โหลดเนื้อหาที่มีลิขสิทธิ์ (คลิกข้อความได้เพื่ออ่านคำปฏิเสธฉบับเต็ม)
7. กดเริ่มและดู progress สามารถกดยกเลิกได้

คุณภาพวิดีโอ URL:

| ตัวเลือก | ความหมาย |
|---|---|
| สูงสุด | คุณภาพสูงสุดที่แหล่งและ yt-dlp เปิดให้ดาวน์โหลด โดยพยายามเลือก H.264/AAC |
| 2160p | คุณภาพที่ใกล้ 2160p (4K) โดยไม่เกินเป้าหมายเมื่อมี format เหมาะสม |
| 1080p | คุณภาพที่ใกล้ 1080p โดยไม่เกินเป้าหมายเมื่อมี format เหมาะสม |
| 720p | คุณภาพที่ใกล้ 720p |
| 480p | คุณภาพที่ใกล้ 480p และมักมีขนาดเล็กกว่า |
| 360p | คุณภาพที่ใกล้ 360p ไฟล์เล็กที่สุด เหมาะกับสัญญาณเน็ตไม่แรงหรือเนื้อหาความละเอียดต่ำ |

Clipora ใช้ yt-dlp แบบ `--no-playlist` ไม่โหลด live stream จำกัดขนาดที่ 10 GB ต่อรายการ และไม่อ่าน config, cookies หรือบัญชีของผู้ใช้ YouTube รุ่นปัจจุบันต้องมี Deno หรือ Node.js เพื่อประมวลผล JavaScript challenge หากชื่อไฟล์มีอยู่แล้ว จะสร้าง `(1)`, `(2)` แทนการเขียนทับ

ข้อควรทราบ:

- เว็บไซต์อาจส่งความละเอียด/codec ไม่ครบตามตัวเลือก จึงเป็นเป้าหมาย ไม่ใช่การรับประกัน
- ในบางวิดีโอ ความละเอียดสูงบางตัวอาจถูกจัดส่งเป็นแบบวิดีโอเท่านั้น (ไม่มีเสียง) หากตัวเลือกที่เลือกไม่มีเสียง ให้ลองตัวเลือกที่ใกล้เคียงหรือเลือก สูงสุด
- MP3/M4A/OPUS เป็นการแปลงแบบ lossy ผ่าน FFmpeg ส่วน WAV/FLAC เป็น lossless
- โหมด MOV: ดาวน์โหลดเป็น MP4 แล้วแปลงเป็น ProRes 422 ในเครื่อง (ต้องใช้ FFmpeg ที่รองรับ `prores_ks`)
- เฟรมเรตที่เลือก (60/30fps) จะจำกัดเฉพาะวิดีโอส่วนบนของไฟล์ผลลัพธ์
- โหมด URL มี network request ไปยังเว็บไซต์ต้นทาง แต่ไม่มีการส่งไฟล์ไปเซิร์ฟเวอร์ของ Clipora
- ใช้เฉพาะสื่อที่เป็นเจ้าของ ได้รับอนุญาต เป็น public domain หรือมี license เหมาะสม
- ไม่รองรับ private/paid media, login, cookies, DRM, playlist หรือ live stream

## 5. แยกเสียงจากไฟล์ในเครื่อง

1. เลือกวิดีโอที่มี audio stream
2. เลือกโฟลเดอร์ปลายทาง
3. เลือก **แยกเสียง**
4. เลือก MP3, M4A, WAV, FLAC หรือ OPUS
5. กด **เริ่มแปลงไฟล์**

### MP3

- ใช้ encoder `libmp3lame`
- ตั้งค่า VBR quality 2
- เหมาะเมื่อเน้นความเข้ากันได้กับโปรแกรมและอุปกรณ์ทั่วไป
- เป็น lossy conversion

### M4A

- ใช้ AAC ที่ 192 kbps ใน container M4A
- มักได้คุณภาพต่อขนาดที่ดี
- เป็น lossy conversion

### WAV

- ใช้ PCM 16-bit (ไม่บีบอัด)
- ขนาดไฟล์ใหญ่ที่สุด
- เป็น lossless conversion

### FLAC

- ใช้ codec FLAC
- lossless แต่มีขนาดเล็กกว่า WAV มาก

### OPUS

- ใช้ encoder `libopus` ที่ 160 kbps
- คุณภาพต่อขนาดดีมาก รองรับน้อยกว่า MP3/M4A บนอุปกรณ์บางรุ่น
- เป็น lossy conversion

การเลือก bitrate/format ที่สูงกว่าไม่สามารถคืนรายละเอียดเสียงที่ต้นฉบับไม่มีได้

หากไฟล์ไม่มีเสียง โปรแกรมจะแจ้ง `ไฟล์นี้ไม่มีเสียงให้แยก` และไม่สร้าง output สำเร็จปลอม

## 6. แยกสเต็มเสียง (เสียงร้อง/ดนตรี)

แยกเสียงร้อง (vocals) และดนตรีประกอบ (instrumental) ออกจากเพลงหรือวิดีโอ โดยประมวลผลบนเครื่องของคุณด้วย Demucs โดยไม่ต้องเชื่อมอินเทอร์เน็ตระหว่างทำงาน

1. เลือกไฟล์เสียง/วิดีโอหรือวางลิงก์ แล้วเลือกโฟลเดอร์ปลายทาง
2. เลือก **แยกสเต็มเสียง**
3. เลือกสเต็มที่ต้องการ: **เสียงร้อง** และ/หรือ **ดนตรีประกอบ**
4. เลือกรูปแบบเอาต์พุต MP3, M4A, WAV, FLAC หรือ OPUS
5. กดเริ่มงาน

ครั้งแรกที่ใช้ ระบบจะเสนอให้ติดตั้งเครื่องมือแยกสเต็ม (ขนาดประมาณ 209 MB) ผ่านหน้าต่างติดตั้ง เมื่อติดตั้งแล้วจะทำงานออฟไลน์ได้ทันที

ไฟล์ผลลัพธ์ใช้ชื่อตามต้นฉบับ เช่น `เพลง_vocals.mp3` และ `เพลง_instrumental.mp3` หากไฟล์มีอยู่แล้ว โปรแกรมจะถามก่อนเขียนทับ

เมื่อแยกเสร็จ โปรแกรมจะสร้างไฟล์ `เพลง_stems.zip` รวมไฟล์สเต็มทั้งหมดไว้ในไฟล์เดียว (ไฟล์แยกแต่ละสเต็มยังคงอยู่ด้วย) เหมาะสำหรับการสำรองหรือส่งต่อไฟล์ทั้งหมด

การแยกสเต็มใช้ CPU และหน่วยความจำมาก โดยเฉพาะเพลงยาวหรือความละเอียดสูง จึงอาจใช้เวลานานกว่าแยกเสียงทั่วไป และยังประมวลผลทีละไฟล์

## 7. อัปเดต yt-dlp

เว็บไซต์อาจเปลี่ยนระบบ ทำให้ลิงก์บางรายการดาวน์โหลดไม่ได้จนกว่า yt-dlp จะอัปเดต

- เปิดแอปแล้ว โปรแกรมจะตรวจอัตโนมัติหลัง 3 วินาที หากพบเวอร์ชันใหม่จะถามให้อัปเดต
- กด **อัปเดต yt-dlp** ที่แถวบนสุดเพื่อตรวจด้วยตนเองได้ทุกเมื่อ
- การอัปเดตดาวน์โหลดจาก GitHub อย่างเป็นทางการ ตรวจ SHA-256 checksum ก่อนแทนที่ไฟล์เดิม

หากยังไม่ได้ติดตั้ง yt-dlp ระบบจะแนะนำให้ติดตั้งผ่านปุ่ม **เครื่องมือ** ก่อน

## 8. แปลง MP4 / MOV (ProRes)

1. เลือกวิดีโอ
2. เลือก **แปลงเป็นวิดีโอ**
3. เลือก MP4 หรือ MOV พร้อมคุณภาพและเฟรมเรต
4. เริ่มงาน

### MP4

Output ใช้ H.264 (`libx264`) และ AAC 192 kbps เมื่อ input มีเสียง หากเป็น silent video ระบบจะสร้าง MP4 ที่ไม่มีเสียงได้

| ตัวเลือก | CRF | ลักษณะ |
|---|---:|---|
| High | 18 | คุณภาพสูงกว่า ไฟล์มักใหญ่กว่า |
| Balanced | 23 | สมดุลและเป็นค่าเริ่มต้น |
| Small | 28 | ไฟล์เล็กลงแต่สูญเสียรายละเอียดมากขึ้น |

CRF ไม่ใช่เปอร์เซ็นต์ ขนาดสุดท้ายขึ้นกับรายละเอียด การเคลื่อนไหว ความยาว และ codec ของต้นฉบับ จึงคำนวณขนาดล่วงหน้าแบบแม่นยำไม่ได้

### MOV (ProRes 422)

- ใช้ encoder `prores_ks` profile HQ/Balanced/Small ตามคุณภาพที่เลือก
- พิกเซล `yuv422p10le` และเสียง PCM 16-bit (ไม่บีบอัด) เพื่อให้ After Effects import ได้โดยตรง
- เหมาะกับการแก้ไขใน Adobe After Effects ที่อ่าน MP4/H.264 ได้ไม่เสถียร
- ไฟล์ใหญ่กว่า MP4 มาก และต้องใช้ FFmpeg build ที่รองรับ `prores_ks` (รุ่นที่รวมมาในตัวติดตั้งรองรับ)

### เฟรมเรต (fps)

- **สูงสุด**: ใช้เฟรมเรตเต็มของวิดีโอผลลัพธ์
- **60fps / 30fps**: จำกัดเฟรมเรตไม่เกินค่าที่เลือก เหมาะกับงานที่ต้องการความสม่ำเสมอหรือใช้ใน timeline คงที่

## 9. ไฟล์ผลลัพธ์

Clipora สร้างชื่อจาก stem ของต้นฉบับ:

| Input | Operation | Output |
|---|---|---|
| `lesson.mp4` | MP3 | `lesson_audio.mp3` |
| `lesson.mp4` | M4A | `lesson_audio.m4a` |
| `lesson.mp4` | WAV | `lesson_audio.wav` |
| `lesson.mov` | MP4 | `lesson_converted.mp4` |
| `lesson.mp4` | MOV/ProRes | `lesson_converted.mov` |
| `song.mp3` | แยกสเต็มเสียง (เสียงร้อง) | `song_vocals.mp3` |
| `song.mp3` | แยกสเต็มเสียง (ดนตรีประกอบ) | `song_instrumental.mp3` |
| `song.mp3` | แยกสเต็มเสียง (ทุกสเต็ม) | `song_vocals.mp3`, `song_drums.mp3`, … และ `song_stems.zip` |

หาก output มีอยู่แล้ว โปรแกรมถามก่อนเขียนทับ กด No เพื่อเก็บไฟล์เดิม จากนั้นย้าย/เปลี่ยนชื่อไฟล์เดิมหรือเลือก destination อื่น

หลังสำเร็จ โปรแกรมตรวจว่า output มีอยู่และไม่ใช่ไฟล์ว่าง ก่อนเสนอเปิดโฟลเดอร์

## 10. คุณภาพและเวลา

- Conversion ใช้ CPU และอาจทำให้พัดลมหมุนเร็ว
- วิดีโอความละเอียดสูงหรือยาวใช้เวลามาก
- โหมด MOV/ProRes ช้ากว่าและใช้พื้นที่มากกว่า MP4 อย่างเห็นได้ชัด โดยเฉพาะคุณภาพ High
- อย่าปิดเครื่อง ถอด drive หรือย้าย input/output ระหว่างงาน
- รักษาพื้นที่ว่างมากกว่าขนาด output ที่คาดไว้
- Progress อิงเวลาที่ FFmpeg ประมวลผลเทียบกับ duration เมื่อ duration เชื่อถือได้
- หาก duration ไม่ทราบ อาจไม่เห็นเปอร์เซ็นต์ต่อเนื่อง แต่ผลสำเร็จยังตรวจจาก exit code และ output

- กด **ยกเลิกงาน** เพื่อหยุด FFmpeg; โปรแกรมจะลบเฉพาะไฟล์ชั่วคราวของงานและไม่แตะต้นฉบับ
- หากปิดหน้าต่างระหว่างงาน โปรแกรมจะถามยืนยันก่อนยกเลิกและรอ cleanup แล้วจึงปิด
- Output เดิมจะไม่ถูกแทนที่จนกว่างานใหม่สำเร็จและผ่านการตรวจ

## 11. ความปลอดภัยและความเป็นส่วนตัว

- ไม่มี account, analytics หรือ telemetry
- ไฟล์ที่เลือกจากเครื่อง พาธ และข้อมูล media ไม่ถูกอัปโหลด
- โหมด URL ส่ง request ไปยังเว็บไซต์ต้นทางผ่าน yt-dlp เพื่อรับสื่อที่ผู้ใช้เลือก
- FFmpeg เป็นโปรแกรมภายนอกที่รันในเครื่อง ควรอัปเดตจากแหล่งเชื่อถือได้
- Media เป็น input ที่ซับซ้อน อย่าเปิดไฟล์ไม่น่าเชื่อถือด้วย FFmpeg build ที่ล้าสมัย
- Clipora ไม่ลบ source
- ใช้กับ media ที่เป็นเจ้าของ ได้รับอนุญาต เป็น public domain หรือมี license เหมาะสม
- อย่าใช้เพื่อข้าม DRM, paywall, login หรือ access control
- เจ้าของสิทธิ์ที่พบว่าวิดีโอของตนถูกดาวน์โหลดผ่าน Clipora ให้คลิก **รายงานได้ที่นี่** ในหน้าหลัก (โหมดลิงก์) เพื่อยื่นรายงาน DMCA ผ่านฟอร์มที่เปิดโปรแกรมอีเมลของคุณ โดยเราไม่เก็บข้อมูลรายงานไว้ในเครื่อง

## 12. ข้อจำกัดปัจจุบัน

- Windows 10/11 x64 เป็น platform ที่มี Setup สำเร็จรูป
- ตัวติดตั้งรวม FFmpeg, yt-dlp และ Deno แล้ว (ขนาดประมาณ 250 MB) ไม่ต้องดาวน์โหลดตอนติดตั้ง; การดาวน์โหลดเครื่องมือใหม่เกิดจากปุ่ม **เครื่องมือ** เท่านั้น
- เครื่องมือแยกสเต็มเสียง (PyTorch/Demucs) ต้องติดตั้งครั้งแรกผ่านปุ่ม **เครื่องมือ** (ประมาณ 209 MB) แล้วจึงทำงานออฟไลน์
- การแยกสเต็มเสียงใช้ CPU/หน่วยความจำสูงและประมวลผลทีละไฟล์
- Setup ยังไม่ได้ code sign จึงอาจเห็นคำเตือน SmartScreen
- ประมวลผลทีละไฟล์
- ยังไม่มี trim, batch, custom output name หรือ preset
- URL รองรับตาม extractor ของ yt-dlp และอาจหยุดทำงานเมื่อเว็บไซต์เปลี่ยน
- ไม่รองรับ playlist, live, private/paid media, login, cookies หรือ DRM
- ไม่รับประกันการเก็บ subtitle, multiple audio tracks, HDR, alpha หรือ metadata ทั้งหมด
- MOV/ProRes ต้องใช้ FFmpeg ที่รองรับ `prores_ks` ถ้าไม่รองรับ โปรแกรมจะแนะนำให้เลือก MP4
- UI ภาษาไทยและยังไม่มีระบบเลือกภาษา
