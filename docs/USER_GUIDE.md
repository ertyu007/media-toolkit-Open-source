# คู่มือผู้ใช้ Clipora

## สารบัญ

1. Clipora ทำอะไร
2. เตรียมเครื่อง
3. เปิดโปรแกรม
4. ดาวน์โหลดจากลิงก์
5. แยกเสียงจากไฟล์ในเครื่อง
6. แยก Stem เสียง (เสียงร้อง/ดนตรี)
7. อัปเดตโปรแกรมและเครื่องมือ
8. แปลง MP4 / MOV (ProRes)
9. ไฟล์ผลลัพธ์
10. คุณภาพและเวลา
11. ความปลอดภัยและความเป็นส่วนตัว
12. ข้อจำกัดปัจจุบัน

## 1. Clipora ทำอะไร

Clipora รับไฟล์วิดีโอในเครื่องเพื่อส่งให้ FFmpeg แยกเสียงหรือแปลงวิดีโอ และรับ URL สาธารณะเพื่อดาวน์โหลดผ่าน yt-dlp ผลลัพธ์ถูกเขียนไปยังโฟลเดอร์ที่ผู้ใช้เลือก ต้นฉบับในเครื่องไม่ถูกแก้ไข

งานที่รองรับ:

- วิดีโอเป็น MP3, M4A, WAV, FLAC หรือ OPUS
- วิดีโอเป็น MP4/H.264 พร้อม AAC เมื่อมีเสียง
- วิดีโอไม่มีเสียงเป็น MP4 ที่ไม่มี audio stream
- วิดีโอเป็น MOV/ProRes 422 (เหมาะกับ Adobe After Effects)
- แยก Stem เสียง (เสียงร้อง/ดนตรี ฯลฯ) บนเครื่องด้วย Demucs
- URL สาธารณะเป็นวิดีโอ MP4/MOV หรือเสียง MP3/M4A/WAV/FLAC/OPUS

ไฟล์ input ที่แสดงใน file picker ได้แก่ MP4, MOV, MKV, AVI, WebM และ M4V ความสำเร็จขึ้นกับ codec ที่ FFmpeg build บนเครื่องรองรับ

## 2. เตรียมเครื่อง

### ผู้ใช้ Windows Setup

ดาวน์โหลด `Clipora-Setup-<version>-x64.exe` จากหน้า Releases ติดตั้งและเปิดโปรแกรม ตัวติดตั้งรวม FFmpeg, yt-dlp และ Deno ไว้ในตัวแล้ว เปิดครั้งแรกเข้าหน้าหลักได้ทันทีโดยไม่ต้องดาวน์โหลดเครื่องมือเพิ่ม

ไม่ต้องติดตั้ง Python ใช้ PowerShell แก้ PATH หรือเปิดด้วย Administrator หากเครื่องมือบางตัวหายหรือเสียหาย เช่น หลังอัปเดตหรือถูกโปรแกรมอื่นลบ เปิดปุ่ม **เครื่องมือ** (แถบข้างซ้าย) จะเจอหน้า **สถานะ** บอกทีละตัวว่าติดตั้งแล้ว (พร้อมเวอร์ชัน) หรือยังไม่ติดตั้งอันไหน แล้วกด **ติดตั้งส่วนที่ขาด** ได้เลยโดยไม่ต้องผ่านหน้ายินดีต้อนรับ/ข้อตกลงซ้ำ ส่วนเปิดครั้งแรกยังเป็น flow เต็มเหมือนเดิม หากยกเลิกระหว่างดาวน์โหลด ตัวช่วยจะหยุดอย่างปลอดภัยและไม่ลบเครื่องมือเดิมที่ใช้งานได้

### นักพัฒนาที่รันจาก source

ติดตั้ง Python 3.10+, FFmpeg, yt-dlp และ Deno/Node จากนั้นรัน `python scripts/check_environment.py` เมื่อทุกหัวข้อขึ้น `[OK]` จึงเปิดด้วย `python app.py`

## 3. เปิดโปรแกรม

รุ่น Setup เปิดจาก Start Menu, Desktop shortcut หรือไฟล์ `Clipora.exe` ในโฟลเดอร์ติดตั้ง ผู้ใช้ source เปิดด้วย:

```powershell
python app.py
```

หน้าต่างประกอบด้วย (จากบนลงล่าง):
- แถบบน: ปุ่ม **☰/«** (เปิด/ซ่อนแถบข้าง ปุ่มเดียวสลับกัน), โลโก้ + เวอร์ชัน

- แถบข้างซ้าย (พับได้): **งานปัจจุบัน**, **ประวัติ**, เมนู**เครื่องมือ**, **อัปเดต yt-dlp**, **ตรวจอัปเดต Clipora**, **สนับสนุนโครงการ**, **คู่มือ**, **รายงานปัญหา**, **รีวิว & พูดคุย** และท้ายแถบมีปุ่ม **⚙ ตั้งค่า** เปิด popup: ทั่วไป (ธีม/เสียง/ตรวจอัปเดต), ค่าเริ่มต้นงาน (โหมด/รูปแบบ/คุณภาพ/FPS/โฟลเดอร์), เกี่ยวกับ (เวอร์ชัน + ปุ่มพับ**ถอนการติดตั้ง**แบบหมดจด) — ทั้งหมดจำลงเครื่อง
- ตัวเลือกโหมดแบบ pill 3 ตัวเลือก: **แยกเสียง / แปลงเป็นวิดีโอ / แยก Stem เสียง** พร้อมคำอธิบาย 1 บรรทัดใต้แถบ — โหมดแยก Stemขึ้น 🔒 จนกว่าจะติดตั้งเครื่องมือ กดแล้วพาไปติดตั้ง
- **แหล่งสื่อ**: สลับ **ไฟล์ / URL**, ช่องกรอก, ปุ่ม**เลือกไฟล์ / วางลิงก์**, บรรทัดรายละเอียด และสวิตช์ยืนยันสิทธิ์ (เฉพาะโหมดลิงก์) — ลากไฟล์จาก Explorer มาวางที่หน้าต่างได้เลย (ไฟล์→ช่องแหล่งสื่อ โฟลเดอร์→ช่องบันทึกที่)
- **บันทึกที่**: ช่องโฟลเดอร์ปลายทาง + ปุ่ม**เลือกโฟลเดอร์** (คลิกช่องเพื่อดูโฟลเดอร์ที่ใช้ล่าสุด)
- **รูปแบบผลลัพธ์**: เลือกรูปแบบเสียง/วิดีโอ, ติ๊กเลือก Stem (โหมดแยก Stem) และปุ่ม **▸ ตัวเลือกเพิ่มเติม** สำหรับคุณภาพ/FPS/ตัดช่วงเวลา
- แถบล่าง: ปุ่มเริ่ม (ข้อความเปลี่ยนตามงาน), status + เปอร์เซ็นต์, progress bar, กล่อง **debug การทำงาน** (เปิดค้าง บันทึกทุกขั้นตั้งแต่พารามิเตอร์งานยันผลลัพธ์) และสรุปผลพร้อมปุ่มเปิดโฟลเดอร์/เปิดไฟล์หลังงานสำเร็จ

ระหว่างประมวลผล Clipora จะล็อกช่องไฟล์ โฟลเดอร์ และตัวเลือกรูปแบบไว้ชั่วคราว เมื่อสำเร็จ ล้มเหลว หรือยกเลิก ระบบจะเปิดให้แก้ไขและเริ่มงานใหม่ได้

อย่าเปิดโปรแกรมด้วย Administrator หากไม่จำเป็น ให้เลือกโฟลเดอร์ที่ user ปกติเขียนได้ เช่น Downloads, Videos หรือโฟลเดอร์งาน

## 4. ดาวน์โหลดจากลิงก์

1. คัดลอก URL สาธารณะที่เป็นรายการเดียว
2. เลือก **วางลิงก์** ในหัวข้อแหล่งที่มา
3. วาง URL ด้วย `Ctrl+V`/`Shift+Insert` หรือกด **วางจากคลิปบอร์ด**
4. เลือกโฟลเดอร์ปลายทาง
5. เลือก **แยกเสียง** แล้วเลือก MP3/M4A/WAV/FLAC/OPUS หรือเลือก **แปลงเป็นวิดีโอ** แล้วเลือกรูปแบบไฟล์ MP4/MOV คุณภาพ และFPS
6. ทำเครื่องหมายยืนยันว่าอ่านและยอมรับ **คำปฏิเสธด้านลิขสิทธิ์** แล้ว และจะไม่ดาวน์โหลดเนื้อหาที่มีลิขสิทธิ์ (คลิกข้อความได้เพื่ออ่านคำปฏิเสธฉบับเต็ม)
7. กดเริ่มและดู progress สามารถกดยกเลิกได้

พรีวิวลิงก์: วาง URL ที่ถูกต้อง การ์ดตัวอย่างจะขึ้นโครง shimmer ทันทีในเลย์เอาต์จริง (รูปซ้าย ข้อความขวา) แล้วแอปจะดึงชื่อคลิป ช่อง ระยะเวลา ขนาดไฟล์โดยประมาณ และภาพปกมาแสดงใต้ช่องกรอก (ไม่ดาวน์โหลดไฟล์) ภาพปกคงอัตราส่วนจริงของต้นฉบับ (ไม่ครอป) ขนาดที่ไม่มีข้อมูลจริงจะคำนวณคร่าวๆ จากความยาวคลิป (โหมดแยกเสียง) ถ้าไม่ขึ้นแสดงว่าเครือข่าย/เว็บต้นทางดึงข้อมูลไม่ได้ — ยังกดเริ่มงานได้ตามปกติ ระหว่างดาวน์โหลดแถบ progress แสดงเปอร์เซ็นต์พร้อมความเร็ว (เช่น `3.2MiB/s`) และเวลาที่เหลือโดยประมาณ

คุณภาพวิดีโอ URL:

| ตัวเลือก | ความหมาย |
|---|---|
| สูงสุด | คุณภาพสูงสุดที่แหล่งและ yt-dlp เปิดให้ดาวน์โหลด โดยพยายามเลือก H.264/AAC |
| 2160p | คุณภาพที่ใกล้ 2160p (4K) โดยไม่เกินเป้าหมายเมื่อมี format เหมาะสม |
| 1080p | คุณภาพที่ใกล้ 1080p โดยไม่เกินเป้าหมายเมื่อมี format เหมาะสม |
| 720p | คุณภาพที่ใกล้ 720p |
| 480p | คุณภาพที่ใกล้ 480p และมักมีขนาดเล็กกว่า |
| 360p | คุณภาพที่ใกล้ 360p ไฟล์เล็กที่สุด เหมาะกับสัญญาณเน็ตไม่แรงหรือเนื้อหาความละเอียดต่ำ |

Clipora ใช้ yt-dlp แบบ `--no-playlist` ไม่โหลด live stream จำกัดขนาดที่ 10 GB ต่อรายการ และไม่อ่าน config, cookies หรือบัญชีของผู้ใช้ YouTube รุ่นปัจจุบันต้องมี Deno หรือ Node.js เพื่อประมวลผล JavaScript challenge หากชื่อไฟล์มีอยู่แล้ว จะถามให้เลือก **เขียนทับ**, **เก็บทั้งสองไฟล์** (สร้าง `(1)`, `(2)`) หรือ **ยกเลิก**

เมื่อเว็บไซต์บล็อกการดาวน์โหลดอัตโนมัติ (เช่น HTTP 403 หรือข้อความ "confirm you're not a bot") Clipora จะลองดาวน์โหลดซ้ำอัตโนมัติด้วยวิธีที่เพิ่มขึ้น: เพิ่ม header เฉพาะเว็บไซต์ (เช่น Referer สำหรับ TikTok), สลับ player client ของ YouTube (android/web_embedded/tv) แล้วใช้การจำลองเบราว์เซอร์ (`--impersonate`) โดยไม่ใช้ cookies หรือเข้าสู่ระบบ หากลองทุกวิธีแล้วยังไม่ได้ จะแจ้งว่าลิงก์นี้ถูกบล็อกหรือต้องอัปเดต yt-dlp

หากแจ้งว่า "เครือข่าย/ISP บล็อกการเข้าถึงเว็บไซต์นี้ (resolve โดเมนไม่ได้)" แสดงว่าถูกบล็อกที่ระดับเครือข่าย/ISP — ให้ลองเปลี่ยน DNS เป็น `1.1.1.1` หรือ `8.8.8.8` หรือใช้ VPN/proxy

ข้อควรทราบ:

- เว็บไซต์อาจส่งความละเอียด/codec ไม่ครบตามตัวเลือก จึงเป็นเป้าหมาย ไม่ใช่การรับประกัน
- ในบางวิดีโอ ความละเอียดสูงบางตัวอาจถูกจัดส่งเป็นแบบวิดีโอเท่านั้น (ไม่มีเสียง) หากตัวเลือกที่เลือกไม่มีเสียง ให้ลองตัวเลือกที่ใกล้เคียงหรือเลือก สูงสุด
- MP3/M4A/OPUS เป็นการแปลงแบบ lossy ผ่าน FFmpeg ส่วน WAV/FLAC เป็น lossless
- โหมด MOV: ดาวน์โหลดเป็น MP4 แล้วแปลงเป็น ProRes 422 ในเครื่อง (ต้องใช้ FFmpeg ที่รองรับ `prores_ks`)
- FPSที่เลือก (60/30fps) จะจำกัดเฉพาะวิดีโอส่วนบนของไฟล์ผลลัพธ์
- โหมด URL มี network request ไปยังเว็บไซต์ต้นทาง แต่ไม่มีการส่งไฟล์ไปเซิร์ฟเวอร์ของ Clipora
- ใช้เฉพาะสื่อที่เป็นเจ้าของ ได้รับอนุญาต เป็น public domain หรือมี license เหมาะสม
- ไม่รองรับ private/paid media, login, cookies, DRM, playlist หรือ live stream

## 5. แยกเสียงจากไฟล์ในเครื่อง

1. เลือกวิดีโอที่มี audio stream
2. เลือกโฟลเดอร์ปลายทาง
3. เลือก **แยกเสียง**
4. เลือก MP3, M4A, WAV, FLAC หรือ OPUS
5. กด **เริ่มแปลงไฟล์**

### MP3

- ใช้ encoder `libmp3lame`
- ตั้งค่า VBR quality 2
- เหมาะเมื่อเน้นความเข้ากันได้กับโปรแกรมและอุปกรณ์ทั่วไป
- เป็น lossy conversion

### M4A

- ใช้ AAC ที่ 192 kbps ใน container M4A
- มักได้คุณภาพต่อขนาดที่ดี
- เป็น lossy conversion

### WAV

- ใช้ PCM 16-bit (ไม่บีบอัด)
- ขนาดไฟล์ใหญ่ที่สุด
- เป็น lossless conversion

### FLAC

- ใช้ codec FLAC
- lossless แต่มีขนาดเล็กกว่า WAV มาก

### OPUS

- ใช้ encoder `libopus` ที่ 160 kbps
- คุณภาพต่อขนาดดีมาก รองรับน้อยกว่า MP3/M4A บนอุปกรณ์บางรุ่น
- เป็น lossy conversion

การเลือก bitrate/format ที่สูงกว่าไม่สามารถคืนรายละเอียดเสียงที่ต้นฉบับไม่มีได้

หากไฟล์ไม่มีเสียง โปรแกรมจะแจ้ง `ไฟล์นี้ไม่มีเสียงให้แยก` และไม่สร้าง output สำเร็จปลอม

### ตัดช่วงเวลา (เฉพาะไฟล์ในเครื่อง)

กด **▸ ตัวเลือกเพิ่มเติม** ใต้ตัวเลือกรูปแบบ จะเห็นช่อง **เริ่ม** และ **ระยะเวลา** (ใช้ได้กับงานไฟล์ในเครื่องในโหมดแยกเสียงและแปลงเป็นวิดีโอ):

- กรอกเป็นวินาที (`90`, `90.5`) หรือ `MM:SS` / `HH:MM:SS` (`1:30`)
- เว้นว่างไว้คือใช้ทั้งไฟล์
- โปรแกรมตรวจรูปแบบก่อนเริ่มงาน และตรวจขอบเขตหลังอ่านไฟล์: จุดเริ่มเกินความยาวไฟล์จะแจ้ง error ส่วนระยะเวลาเกินส่วนที่เหลือจะตัดแค่ส่วนที่เหลือให้
- เปอร์เซ็นต์ความคืบหน้าคิดจากความยาวของช่วงที่ตัดจริง

## 6. แยก Stem เสียง (เสียงร้อง/ดนตรี)

แยกเสียงร้อง (vocals) และดนตรีประกอบ (instrumental) ออกจากเพลงหรือวิดีโอ โดยประมวลผลบนเครื่องของคุณด้วย Demucs โดยไม่ต้องเชื่อมอินเทอร์เน็ตระหว่างทำงาน

1. เลือกไฟล์เสียง/วิดีโอหรือวางลิงก์ แล้วเลือกโฟลเดอร์ปลายทาง
2. เลือก **แยก Stem เสียง**
3. เลือก Stem ที่ต้องการ: **เสียงร้อง** และ/หรือ **ดนตรีประกอบ**
4. เลือกรูปแบบเอาต์พุต MP3, M4A, WAV, FLAC หรือ OPUS
5. กดเริ่มงาน

ครั้งแรกที่ใช้ ระบบจะเสนอให้ติดตั้งเครื่องมือแยก Stem (ขนาดประมาณ 209 MB) ผ่านหน้าต่างติดตั้ง เมื่อติดตั้งแล้วจะทำงานออฟไลน์ได้ทันที

ไฟล์ผลลัพธ์ใช้ชื่อตามต้นฉบับ หากไฟล์มีอยู่แล้ว โปรแกรมจะถามให้เลือก **เขียนทับ**, **เก็บทั้งสองไฟล์** หรือ **ยกเลิก** ก่อนเริ่มงาน

- เลือก Stem เดี่ยว (เช่น เสียงร้องอย่างเดียว) → ได้ไฟล์เสียงเดียว เช่น `เพลง_vocals.mp3` ไม่บีบ zip
- เลือกหลาย Stem → ได้ไฟล์เดียว `เพลง_stems.zip` รวมทุก Stemไว้ข้างใน

การแยก Stemใช้ CPU และหน่วยความจำมาก โดยเฉพาะเพลงยาวหรือความละเอียดสูง จึงอาจใช้เวลานานกว่าแยกเสียงทั่วไป และยังประมวลผลทีละไฟล์

## 7. อัปเดตโปรแกรมและเครื่องมือ

### การอัปเดต Clipora
- เมื่อเปิดโปรแกรม Clipora จะตรวจสอบเวอร์ชันใหม่จาก GitHub Releases อัตโนมัติหลังเปิดแอป 5 วินาที
- หากพบเวอร์ชันใหม่ จะแสดงหน้าต่างแจ้งเตือนพร้อมบันทึกการเปลี่ยนแปลง (Release Notes) และตัวเลือก:
  - **อัปเดตทันที**: เปิดเว็บเบราว์เซอร์ไปยังหน้าดาวน์โหลดตัวติดตั้งเวอร์ชันใหม่ล่าสุด
  - **เตือนฉันภายหลัง**: ปิดหน้าต่างและแจ้งเตือนอีกครั้งในการเปิดครั้งถัดไป
  - **ข้ามเวอร์ชันนี้**: บันทึกข้ามเวอร์ชันนี้และจะไม่แจ้งเตือนซ้ำจนกว่าจะมีเวอร์ชันใหม่กว่า
- ตรวจสอบด้วยตนเองได้ทุกเมื่อที่แถบข้างซ้าย → **ตรวจอัปเดต Clipora...**

### การอัปเดต yt-dlp
เว็บไซต์อาจเปลี่ยนระบบ ทำให้ลิงก์บางรายการดาวน์โหลดไม่ได้จนกว่า yt-dlp จะอัปเดต

- เปิดแอปแล้ว โปรแกรมจะตรวจอัตโนมัติหลัง 3 วินาที หากพบเวอร์ชันใหม่จะแค่แจ้งเตือน (ไม่โหลดเอง) — กดอัปเดตเมื่อพร้อมได้เลย
- กดแถบข้างซ้าย → **อัปเดต yt-dlp (Ctrl+U)** เพื่อตรวจและอัปเดตด้วยตนเองได้ทุกเมื่อ (จะถามยืนยันก่อน)
- การอัปเดตดาวน์โหลดจาก GitHub อย่างเป็นทางการ ตรวจ SHA-256 checksum ก่อนแทนที่ไฟล์เดิม

หากยังไม่ได้ติดตั้ง yt-dlp ระบบจะแนะนำให้ติดตั้งผ่านเมนู **เครื่องมือ (Ctrl+T)** ก่อน

## 8. แปลง MP4 / MOV (ProRes)

1. เลือกวิดีโอ
2. เลือก **แปลงเป็นวิดีโอ**
3. เลือก MP4 หรือ MOV พร้อมคุณภาพและFPS
4. เริ่มงาน

### MP4

Output ใช้ H.264 (`libx264`) และ AAC 192 kbps เมื่อ input มีเสียง หากเป็น silent video ระบบจะสร้าง MP4 ที่ไม่มีเสียงได้

| ตัวเลือก | CRF | ลักษณะ |
|---|---:|---|
| High | 18 | คุณภาพสูงกว่า ไฟล์มักใหญ่กว่า |
| Balanced | 23 | สมดุลและเป็นค่าเริ่มต้น |
| Small | 28 | ไฟล์เล็กลงแต่สูญเสียรายละเอียดมากขึ้น |

CRF ไม่ใช่เปอร์เซ็นต์ ขนาดสุดท้ายขึ้นกับรายละเอียด การเคลื่อนไหว ความยาว และ codec ของต้นฉบับ จึงคำนวณขนาดล่วงหน้าแบบแม่นยำไม่ได้

### MOV (ProRes 422)

- ใช้ encoder `prores_ks` profile HQ/Balanced/Small ตามคุณภาพที่เลือก
- พิกเซล `yuv422p10le` และเสียง PCM 16-bit (ไม่บีบอัด) เพื่อให้ After Effects import ได้โดยตรง
- เหมาะกับการแก้ไขใน Adobe After Effects ที่อ่าน MP4/H.264 ได้ไม่เสถียร
- ไฟล์ใหญ่กว่า MP4 มาก และต้องใช้ FFmpeg build ที่รองรับ `prores_ks` (รุ่นที่รวมมาในตัวติดตั้งรองรับ)

### FPS

- **สูงสุด**: ใช้FPSเต็มของวิดีโอผลลัพธ์
- **60fps / 30fps**: จำกัดFPSไม่เกินค่าที่เลือก เหมาะกับงานที่ต้องการความสม่ำเสมอหรือใช้ใน timeline คงที่

## 9. ไฟล์ผลลัพธ์

Clipora สร้างชื่อจาก stem ของต้นฉบับ:

| Input | Operation | Output |
|---|---|---|
| `lesson.mp4` | MP3 | `lesson_audio.mp3` |
| `lesson.mp4` | M4A | `lesson_audio.m4a` |
| `lesson.mp4` | WAV | `lesson_audio.wav` |
| `lesson.mov` | MP4 | `lesson_converted.mp4` |
| `lesson.mp4` | MOV/ProRes | `lesson_converted.mov` |
| `song.mp3` | แยก Stem เสียง (เสียงร้องอย่างเดียว) | `song_vocals.mp3` |
| `song.mp3` | แยก Stem เสียง (หลาย Stem) | `song_stems.zip` |

หาก output มีอยู่แล้ว โปรแกรมถามให้เลือก **เขียนทับ**, **เก็บทั้งสองไฟล์** หรือ **ยกเลิก** ก่อนเริ่มงาน — เลือกเก็บทั้งสองไฟล์เพื่อให้ได้ชื่อ `(1)`, `(2)` โดยไม่ลบไฟล์เดิม

หลังสำเร็จ แถบด้านล่างแสดง **สรุปผลลัพธ์** (ชื่อไฟล์ + ขนาดรวม) พร้อมปุ่ม **เปิดโฟลเดอร์** และ **เปิดไฟล์** (กรณีไฟล์เดียว) เพื่อเปิดดูผลลัพธ์ได้ทันที

### ประวัติดาวน์โหลด

ทุกงานที่สำเร็จถูกบันทึกอัตโนมัติ เปิดดูที่แถบข้างซ้าย → **ประวัติ** (ไม่ต้องเปิดหน้าต่างแยก):

- เห็นชื่องาน ประเภท (เพลง/วิดีโอ/Stem) วันเวลา และที่อยู่ไฟล์
- แถวประวัติเป็นคอลัมน์แบบ Explorer: **ชื่อ / ประเภท / วันที่ / ขนาด** (ไฟล์หายขึ้น `—`)
- รายการที่คลิกเลือกไว้ถูกจำไว้ กลับมาหน้านี้หรือเปิดแอปใหม่ยังเลือกอยู่ที่เดิม
- กรองด้วยแถบ **ทั้งหมด / เพลง / วิดีโอ / Stem / ถังขยะ** กด **ถังขยะ** เพื่อดูของที่ลบ กด **ทั้งหมด** เพื่อกลับมา
- ดับเบิลคลิกหรือคลิกขวา → **เปิดโฟลเดอร์** เพื่อเปิดโฟลเดอร์
- การลบทำผ่านคลิกขวาอย่างเดียว (แถวไม่มีปุ่ม): **ลบรายการนี้**ถามยืนยันก่อน แล้วย้ายไป**ถังขยะ** (กู้คืนได้ ของในถังขยะหายถาวรเองใน 30 วัน) — ไฟล์จริงไม่ถูกลบเสมอ
- คลิกขวาที่ว่างเพื่อเปิดเมนู: เปิดโฟลเดอร์ / ลบรายการนี้ / ล้างถังขยะ (ในถังขยะ: กู้คืน / ลบถาวร / ล้างถังขยะ) — แถวถังขยะไม่มีปุ่ม ทำทุกอย่างผ่านคลิกขวา
- ไฟล์ที่ถูกย้าย/ลบไปแล้วจะขึ้นว่า (ไฟล์หาย)

## 10. คุณภาพและเวลา
- Conversion ใช้ CPU และอาจทำให้พัดลมหมุนเร็ว
- วิดีโอความละเอียดสูงหรือยาวใช้เวลามาก
- โหมด MOV/ProRes ช้ากว่าและใช้พื้นที่มากกว่า MP4 อย่างเห็นได้ชัด โดยเฉพาะคุณภาพ High
- อย่าปิดเครื่อง ถอด drive หรือย้าย input/output ระหว่างงาน
- รักษาพื้นที่ว่างมากกว่าขนาด output ที่คาดไว้
- Progress อิงเวลาที่ FFmpeg ประมวลผลเทียบกับ duration เมื่อ duration เชื่อถือได้
- หาก duration ไม่ทราบ อาจไม่เห็นเปอร์เซ็นต์ต่อเนื่อง แต่ผลสำเร็จยังตรวจจาก exit code และ output

- กด **ยกเลิกงาน** เพื่อหยุด FFmpeg; โปรแกรมจะลบเฉพาะไฟล์ชั่วคราวของงานและไม่แตะต้นฉบับ
- หากปิดหน้าต่างระหว่างงาน โปรแกรมจะถามยืนยันก่อนยกเลิกและรอ cleanup แล้วจึงปิด
- Output เดิมจะไม่ถูกแทนที่จนกว่างานใหม่สำเร็จและผ่านการตรวจ

## 11. ความปลอดภัยและความเป็นส่วนตัว

- ไม่มี account, analytics หรือ telemetry
- ไฟล์ที่เลือกจากเครื่อง พาธ และข้อมูล media ไม่ถูกอัปโหลด
- โหมด URL ส่ง request ไปยังเว็บไซต์ต้นทางผ่าน yt-dlp เพื่อรับสื่อที่ผู้ใช้เลือก
- FFmpeg เป็นโปรแกรมภายนอกที่รันในเครื่อง ควรอัปเดตจากแหล่งเชื่อถือได้
- Media เป็น input ที่ซับซ้อน อย่าเปิดไฟล์ไม่น่าเชื่อถือด้วย FFmpeg build ที่ล้าสมัย
- Clipora ไม่ลบ source
- ใช้กับ media ที่เป็นเจ้าของ ได้รับอนุญาต เป็น public domain หรือมี license เหมาะสม
- อย่าใช้เพื่อข้าม DRM, paywall, login หรือ access control

## 12. ข้อจำกัดปัจจุบัน

- Windows 10/11 x64 เป็น platform ที่มี Setup สำเร็จรูป
- ตัวติดตั้งรวม FFmpeg, yt-dlp และ Deno แล้ว (ขนาดประมาณ 250 MB) ไม่ต้องดาวน์โหลดตอนติดตั้ง; การดาวน์โหลดเครื่องมือใหม่เกิดจากปุ่ม **เครื่องมือ** เท่านั้น
- เครื่องมือแยก Stem เสียง (PyTorch/Demucs) ต้องติดตั้งครั้งแรกผ่านปุ่ม **เครื่องมือ** (ประมาณ 209 MB) แล้วจึงทำงานออฟไลน์
- ก่อนเริ่มงานทุกครั้ง โปรแกรมตรวจพื้นที่ดิสก์ของโฟลเดอร์ปลายทาง และล้างโฟลเดอร์ชั่วคราว (`.clipora-*`) ที่ค้างจากงานก่อนให้อัตโนมัติ หากพื้นที่เต็มจะแจ้งเตือนและยังไม่เริ่มงาน
- การแยก Stem เสียงใช้ CPU/หน่วยความจำสูงและประมวลผลทีละไฟล์
- build ที่ไม่ได้ลงนาม code signing อาจเห็นคำเตือน SmartScreen (ดู [CODE_SIGNING.md](CODE_SIGNING.md))
- ประมวลผลทีละไฟล์
- ยังไม่มี batch (คิวงานหลายไฟล์), custom output name หรือ preset
- URL รองรับตาม extractor ของ yt-dlp และอาจหยุดทำงานเมื่อเว็บไซต์เปลี่ยน
- ไม่รองรับ playlist, live, private/paid media, login, cookies หรือ DRM
- ไม่รับประกันการเก็บ subtitle, multiple audio tracks, HDR, alpha หรือ metadata ทั้งหมด
- MOV/ProRes ต้องใช้ FFmpeg ที่รองรับ `prores_ks` ถ้าไม่รองรับ โปรแกรมจะแนะนำให้เลือก MP4
- UI ภาษาไทยและยังไม่มีระบบเลือกภาษา

หากพบปัญหา ให้ทำตาม [TROUBLESHOOTING.md](TROUBLESHOOTING.md) และแนบข้อมูลที่ไม่เปิดเผยข้อมูลส่วนตัวเมื่อเปิด issue
