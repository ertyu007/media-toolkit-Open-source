แยกเสียงร้องและเครื่องดนตรี

ทุกงานผ่านด่านเดียวกัน

ไม่ว่าจะเริ่มจากไฟล์ ลิงก์ หรือ Stem งานจะถูกตรวจก่อนเริ่ม ประมวลผลใน worker แยก และตรวจผลลัพธ์ก่อนแจ้งว่าสำเร็จ

  1. รับงาน

    เลือกไฟล์ วางลิงก์ หรือขอแยก Stem พร้อมตัวเลือกที่ต้องการ

    Input

  2. ตรวจสอบ

    probe stream ตรวจตัวเลือก และเช็กพื้นที่ดิสก์ก่อนเริ่มงาน

    Validate

  3. ประมวลผล

    FFmpeg, yt-dlp หรือ Demucs ทำงานใน worker แยกจากหน้าจอ

    Render

  4. ตรวจผล

    ยืนยัน exit 0 ขนาดและ stream ของไฟล์ ก่อนเปิดให้ใช้งาน

    Verify
ไฟล์ FFprobe + FFmpeg ลิงก์ yt-dlp + FFmpeg Stem Demucs + _stems.zip

แผนภาพจำลอง — หน้านี้ไม่ประมวลผลหรือดาวน์โหลดสื่อจริง
