Clipora

โปรแกรมเดสก์ท็อป Windows แปลงวิดีโอ แยกเสียง ดาวน์โหลดสื่อสาธารณะที่ได้รับอนุญาต — ประมวลผลบนเครื่องทั้งหมด ฟรี ไม่มีโฆษณา ไม่ต้องสมัครบัญชี

เวอร์ชัน 0.6.4 · Python 3.10+ · Tkinter · FFmpeg + yt-dlp + Demucs
ดาวน์โหลด (tag pc-v*) · ซอร์สโค้ด · คู่มือผู้ใช้ คู่มือผู้ใช้ (md)

1. ภาพรวมระบบ

Clipora เป็นแอป local-first: ไฟล์ต้นฉบับไม่ถูกแก้ไข ไม่ส่งไฟล์/ลิงก์ไปเซิร์ฟเวอร์ของ Clipora เก็บ output เดิมไว้จนกว่างานใหม่จะสำเร็จ ใช้งาน 3 ขั้นตอน: วางลิงก์/เลือกไฟล์ → เลือกรูปแบบ → กดเริ่ม

ไฟล์ในเครื่อง
แยกเสียง MP3/M4A/WAV/FLAC/OPUS · แปลง MP4 (H.264/AAC) · MOV ProRes 422 · ตัดช่วงเวลา · เลือก FPS สูงสุด/60/30 · คุณภาพ High/Balanced/Small
ลิงก์สาธารณะ
ทีละรายการผ่าน yt-dlp (สูงสุด/2160p/1080p/720p/480p/360p) · ไม่รับ playlist, live, private/paid, login, cookies, DRM
แยก Stem
เสียงร้อง/ดนตรี ฯลฯ บนเครื่องด้วย Demucs (ออฟไลน์หลังติดตั้ง ~209 MB) พร้อมไฟล์ _stems.zip

Setup รวม Python/Tkinter + FFmpeg + yt-dlp + Deno (~250 MB) เปิดครั้งแรกใช้ได้ทันที ไม่ต้องต่อเน็ตตอนติดตั้ง

2. สถาปัตยกรรม

app.py (entry)→ CliporaApp clipora/ui.py (main thread)→ snapshot JobSpec/ImportSpec→ worker thread→ ffmpeg.py / importer.py / separator.py→ after() กลับมาอัปเดต UI
งานไฟล์ในเครื่อง
probe (ffprobe JSON) → validate_operation → normalize_trim → build_command → รัน FFmpeg → finalize_output (ตรวจ exit 0 + ขนาด > 0)
งาน URL
validate_url → build_import_command (yt-dlp + --ignore-config) → ดาวน์โหลดลง workspace .clipora-import-* ชั่วคราว → finalize ชื่อชนกันเป็น (1)/(2) → ล้าง temp
แยก Stem
separate_audio (Demucs) → separate_expected_outputs → รวม _stems.zip · ต้องติดตั้งเครื่องมือก่อนครั้งแรกผ่านปุ่ม เครื่องมือ
กฎเหล็ก
ห้ามแตะ Tk จาก worker · subprocess แบบ argument list (shell=False) + ซ่อน console · ถือ process handle ตอนยกเลิก (URL ต้องหยุดทั้ง tree yt-dlp→FFmpeg) · source ห้ามเป็น cleanup target · ตรวจพื้นที่ดิสก์ก่อนเริ่ม

clipora/tools.py ค้นหา FFmpeg/yt-dlp/Denodependencies.py พิน URL+SHA-256history.py ประวัติ/ถังขยะpreview.py พรีวิวลิงก์app_update.py / ytdlp_update.py อัปเดต
