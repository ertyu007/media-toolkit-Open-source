# Clipora PC — Activity Log (บันทึกกิจกรรมและการพัฒนา)

ไฟล์นี้ใช้สำหรับบันทึกรายละเอียดการทำงาน การเปลี่ยนแปลง และสถานะของโปรเจกต์ Clipora PC ในทุกช่วงเวลา

---

## แผนงานการพัฒนา (Roadmap)
1. [x] สร้างระบบบันทึกกิจกรรม (`docs/ACTIVITY_LOG.md`)
2. [ ] ระบบคิวงาน (Batch Processing) — ยังไม่มีโค้ด ต้องเริ่มใหม่
3. [x] ระบบตัดช่วงเวลา (Media Trimming) — ใช้ได้กับงานไฟล์ในเครื่องโหมดแยกเสียง/แปลงวิดีโอ (งาน URL/stems ยังไม่รองรับ)
4. [x] ระบบตรวจสอบพื้นที่ดิสก์ว่างล่วงหน้า (Disk Space Check) — ตรวจก่อนเริ่มงานทุกครั้ง
5. [x] ระบบตรวจสอบความสมบูรณ์ของไฟล์ต้นทาง (Source File Integrity Check)
6. [x] ระบบล้างแคชชั่วคราวตกค้าง (Orphaned Cache Cleanup) — ล้างก่อนเริ่มงานทุกครั้ง
7. [x] ปุ่มคัดลอก Error Log สะดวกๆ (`ErrorDialog` พร้อมปุ่ม Copy)
8. [x] ระบบแจ้งเตือนการอัปเดตแอปพลิเคชันหลัก (App Update Notification)
9. [ ] ระบบจำกัดทรัพยากรการประมวลผล (CPU/Thread Limiter สำหรับ Demucs) — มี `separator_environment(max_threads)` แต่ยังเรียกแบบไม่จำกัด

---

## ประวัติการทำงาน

### 2026-08-21
- เริ่มต้นจัดทำแผนงานพัฒนา 12 หัวข้อ (ยกเว้นเรื่องคุกกี้)
- สร้างไฟล์ `docs/ACTIVITY_LOG.md` เพื่อบันทึกประวัติการเปลี่ยนแปลงในไฟล์เดียว
- พัฒนาและเพิ่มฟีเจอร์สำคัญ:
  1. ระบบล้างแคชชั่วคราวตกค้าง (Orphaned Cache Cleanup) — ต่อสายเรียกก่อนเริ่มงานทุกครั้ง
  2. ปุ่มคัดลอก Error Log สะดวกๆ (`ErrorDialog`)
  3. ระบบตรวจสอบพื้นที่ดิสก์ว่างล่วงหน้า (Disk Space Check) — ต่อสายเรียกก่อนเริ่มงานทุกครั้ง
  4. ระบบตรวจสอบความสมบูรณ์ของไฟล์ต้นทาง (Source File Integrity Check)
  5. ระบบตัดช่วงเวลา (Media Trimming) — ต่อสายช่องกรอกเข้ากับงานไฟล์ในเครื่อง (โหมดแยกเสียง/แปลงวิดีโอ)
  6. ระบบแจ้งเตือนการอัปเดตแอปพลิเคชันหลัก (App Update Notification)
- ยังไม่ทำ: ระบบคิวงาน (Batch — ไม่มีโค้ด), CPU/Thread Limiter (มีฟังก์ชันแต่ยังไม่เรียกแบบจำกัด)
- รัน Unit/Integration Tests ผ่านทั้งหมด 203 tests ครบถ้วนสมบูรณ์
