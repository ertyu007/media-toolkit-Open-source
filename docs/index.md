# Clipora

Clipora คือโปรแกรมเดสก์ท็อปสำหรับ Windows ใช้แปลงวิดีโอ แยกเสียง และดาวน์โหลดสื่อสาธารณะที่ได้รับอนุญาต ประมวลผลบนเครื่องทั้งหมด

## คุณสมบัติหลัก

- แปลงวิดีโอเป็น MP4 / MOV
- แยกเสียงเป็น MP3 / M4A / WAV / FLAC / OPUS
- แยก Stem เสียง (เสียงร้อง/ดนตรี) บนเครื่องด้วย Demucs
- ดาวน์โหลดจาก URL สาธารณะ
- อินเทอร์เฟซภาษาไทย
- ฟรี ไม่มีโฆษณา ไม่ต้องสมัครบัญชี

## ดาวน์โหลด

ดาวน์โหลดเวอร์ชันล่าสุดได้ที่ [หน้า Releases](https://github.com/ertyu007/media-toolkit-Open-source/releases)

ความต้องการระบบ: Windows 10/11 x64
